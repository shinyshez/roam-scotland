Snow data — ERA5 / ERA5-Land reanalysis via the Open-Meteo historical weather API, fetched by your browser when this page loads. Reanalysis snow depth is a model estimate on a ~10 km grid, not a gauge reading; treat the city values as "the grid cell containing that city". Values are the mean across the selected cities, each weighted equally — that is a station-style average, not an area-weighted national mean.

ENSO data — the Oceanic Niño Index (ONI), 3-month running mean SST anomaly in the Niño 3.4 region. Each December is classified by the NDJ season centred on it, so December 1997 carries the 1997–98 El Niño. The page first tries to pull the live table from NOAA PSL; if that request is blocked by CORS it falls back to the snapshot bundled in this file (ONI_SNAPSHOT) — the status line above says which is in use. To refresh the snapshot, paste the December (NDJ) column from the CPC ONI table.

Reading it — ENSO's fingerprint on Central Asian winters is indirect and weak compared with its grip on, say, the Pacific rim. Expect a lot of year-to-year noise and a small difference between the phase averages; the significance line in the tiles is a Welch t-test on those two groups and is there to keep the eye honest.
